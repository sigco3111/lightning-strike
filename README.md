
# 라이트닝 스트라이크 (Lightning Strike)

화면을 클릭하여 강력하고 사실적인 번개를 소환하고, 화면에 나타나는 다양한 오브젝트를 파괴하는 아케이드 스타일의 웹 게임입니다. 에너지를 전략적으로 관리하고, 업그레이드를 통해 번개를 강화하며, 최대한 높은 점수를 획득하는 것이 목표입니다.

실행주소1 : https://lightning-strike-gilt.vercel.app/

실행주소2 : https://dev-canvas-pi.vercel.app/

## 🎮 주요 기능

*   **동적 번개 효과**: 클릭 한 번으로 화면에 역동적이고 시각적으로 만족스러운 번개를 생성합니다.
*   **다양한 상호작용 오브젝트**: 각기 다른 특성과 전략적 가치를 지닌 여러 종류의 오브젝트가 등장합니다.
*   **연쇄 번개 시스템**: 금속(⚙️)이나 수정(💎) 같은 전도성 오브젝트를 타격하여 주변의 다른 전도체로 번개가 연쇄적으로 뻗어 나가게 할 수 있습니다.
*   **특수 효과**:
    *   **폭발**: 폭발성 통(💣)을 파괴하여 주변에 광역 피해를 줍니다.
    *   **소용돌이**: 소용돌이 수정(🌀)을 파괴하면 주변의 모든 오브젝트를 중심으로 끌어당긴 후 폭발시켜 막대한 피해를 입힙니다.
    *   **슈퍼차지**: 유물(⭐)을 파괴하면 다음 번개가 한층 강화되어 더 넓은 범위에 강력한 피해를 줍니다.
*   **자원 및 업그레이드 시스템**:
    *   **에너지**: 번개 사용 시 소모되며, 시간이 지남에 따라 자동으로 회복됩니다.
    *   **재료(Shards)**: 오브젝트를 파괴하여 💎를 획득하고, 이를 사용해 번개 위력, 에너지 시스템 등 다양한 능력을 영구적으로 업그레이드할 수 있습니다.
*   **점진적 난이도 상승**: 게임이 진행될수록 오브젝트의 생성 속도가 빨라지고 체력이 증가하여 더욱 도전적인 환경을 제공합니다.
*   **콤보 시스템**: 연속으로 오브젝트를 파괴하여 콤보를 쌓고 추가 점수를 획득하세요.
*   **상세한 게임 오버 화면**: 최종 점수와 함께 게임 플레이 중 발생한 주요 이벤트(번개, 파괴, 폭발 등)의 히스토리를 시각적인 맵으로 제공하여 플레이를 복기할 수 있습니다.

## 🕹️ 플레이 방법

1.  **번개 소환**: 화면의 원하는 위치를 클릭하여 번개를 내리칩니다. 번개를 사용할 때마다 에너지가 소모됩니다.
2.  **오브젝트 파괴**: 번개를 이용해 화면의 오브젝트들을 파괴하세요. 파괴 시 점수와 업그레이드 재료(💎)를 얻습니다.
3.  **에너지 관리**: 에너지가 모두 소모되면 번개를 사용할 수 없습니다. 에너지가 다시 채워질 때까지 기다리세요. 수정(💎)을 파괴하면 에너지를 즉시 회복할 수 있습니다.
4.  **전략적 플레이**: 각 오브젝트의 특성을 활용하세요. 전도체로 연쇄 번개를 유도하고, 폭탄으로 밀집된 지역을 정리하는 등 효율적인 전략을 구사하세요.
5.  **업그레이드**: 화면 우측 상단의 '업그레이드' 버튼을 눌러 모은 재료로 당신의 능력을 강화하세요.
6.  **생존**: 화면이 오브젝트로 가득 차면(최대 50개) 게임이 종료됩니다. 최대한 오래 살아남아 최고 점수를 기록하세요!

## 🧱 오브젝트 종류

| 이모지 | 이름           | 설명                                                                                                                                     |
| :----: | :------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
|   🪨   | **돌 (Stone)**     | 가장 기본적인 오브젝트입니다. 가끔 푸른색 보호막을 두르고 나타나며, 보호막은 한 번의 번개 공격을 완전히 흡수합니다.                         |
|   ⚙️   | **금속 (Metal)**     | 전도체입니다. 금속에 번개를 맞추면 주변의 다른 전도체로 연쇄 번개가 이어집니다.                                                           |
|   💎   | **수정 (Crystal)**   | 전도체이며, 파괴 시 즉시 일정량의 에너지를 회복시켜 줍니다.                                                                              |
|   💣   | **폭발성 통** | 파괴되면 강력한 폭발을 일으켜 주변 넓은 범위의 오브젝트들에게 피해를 줍니다.                                                                |
|   ⭐   | **유물 (Relic)**     | 파괴 시 다음 한 번의 번개를 '슈퍼차지' 상태로 만듭니다. 슈퍼차지된 번개는 피해량과 범위가 대폭 증가합니다.                               |
|   🌀   | **소용돌이 수정** | 파괴 시 주변의 모든 오브젝트를 중심으로 끌어당겨 한 점에 모은 뒤, 강력한 내파(implosion)를 일으켜 큰 피해를 줍니다.                      |

## 🛠️ 기술 스택

*   **프레임워크**: React.js
*   **언어**: TypeScript
*   **스타일링**: Tailwind CSS (CDN을 통해 사용)
*   **렌더링**: DOM 렌더링 (SVG 및 CSS 애니메이션)
*   **모듈**: `esm.sh`를 통한 Native ES Modules
